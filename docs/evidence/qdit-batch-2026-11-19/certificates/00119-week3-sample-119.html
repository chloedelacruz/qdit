How to verify

This page carries its inclusion-proof file (qdit-inclusion-proof/v2) in a script block. Only that block is checked; the text above is a rendering of it.

With qdit-batch from github.com/chloedelacruz/qdit (packages/qdit-batch):

qdit-batch verify <this file>            # against the root stored on chain
qdit-batch verify --offline <this file>  # the file agrees with itself, no network

The on-chain check reads the root with get_batch and asks the contract's own verify_inclusion. Both are simulations: no key and no fee. An offline check alone proves only that the file is consistent, not that its root was anchored.
